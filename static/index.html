MISSION PROTOCOL

TIC-TAC-TOE: Choose 1 PLAYER / VS COMPUTER or 2 PLAYER / NETWORK. In solo mode you are X and M.U.S.A. is O; play starts immediately. In network mode Player 1 is X, Player 2 is O. The host initializes the match; X moves first. Select an empty square on your turn. Three matching marks in a row, column, or diagonal win. A full board with no winner is a draw. The host can start a new match after either result.

01 / CONNECT

Create a room and give its code to a second player. The host starts when both are present.

02 / EXPLORE

Turn LEFT or RIGHT; move one cell FORWARD. Both operators reveal the same map as they explore. Blank space is unknown.

03 / ACTIVATE

Find both hidden relays. Either operator can discover one, but only its assigned operator activates it by stepping onto it.

04 / EXTRACT

After both relays activate, bring both operators onto the extraction tile. Walls block movement; interference delays controls for three seconds.
